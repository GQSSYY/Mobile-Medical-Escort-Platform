## 📖 项目背景与简介

随着老龄化社会的发展与异地就医需求的激增，老年人、孕妇、行动不便患者在就医过程中面临流程复杂、家属无暇陪同等痛点。

**移动医疗护送平台**致力于打通病患就医“最后一公里”，提供专业、安全、贴心的全流程就医陪诊与出入院护送服务：
- **用户移动 H5 端 (`pzH5`)**：为就诊人及家属提供便捷的医院检索、陪诊项目预约、陪诊师选择、在线即时支付与履约进度追踪。
- **运营后台管理端 (`pzadmin`)**：为平台运营团队提供可视化权限管控、陪诊师资质认证与排班调度、全站订单流转监控及数据统筹。

## 📱 双端业务功能

### 1. 用户移动端 (`pzH5`)

- 🏥 **医院检索与科室导航**：支持根据医院级别、区域进行快速检索，查看院区指引与特色专科。
- 🛎️ **陪诊服务矩阵**：涵盖门诊全程陪诊、代办挂号取药、检查陪同、出入院专车护送等多种定制服务套餐。
- 👨‍⚕️ **专业陪诊师挑选**：展示陪诊人员资质认证、从业年限、服务星级及历史真实好评。
- 📝 **极速预约与就诊人管理**：支持维护多个常用就诊人信息（姓名、身份证、病历卡、健康诉求等），一键快捷代填。
- ⏱️ **订单状态监控与支付**：
  - 支持“待支付、待服务、已完成、已取消”全状态流转。
  - 精确支付有效倒计时（超时自动关闭并释放资源）。
  - 集成微信/支付宝收银台与动态二维码支付。
- 👤 **个人中心**：历史订单列表、优惠券、紧急联系人、意见反馈与隐私协议。

### 2. 运营管理后台 (`pzadmin`)

- 🔐 **管理员身份与鉴权体系**：支持超级管理员与普通运营人员登录，配合图形验证码与安全会话。
- 🧭 **动态路由与菜单权限 (RBAC)**：登录后依据服务端下发的权限点列表动态挂载路由表，未授权路由阻断拦截，确保菜单与路由实时高亮同步。
- 👥 **系统账号管理**：支持角色增删改查、权限分配、账号启用/禁用及密码重置。
- 🩺 **陪诊人员管理**：陪诊师建档、实名认证审核、服务区域绑定、在线状态与接单上限调度控制。
- 📊 **订单调度中心**：支持订单编号、下单时间、订单状态、服务人员等多条件复合筛选；支持手工改派与退款异常干预。

## 💡 核心技术亮点与问题攻坚

在实际研发与上线联调过程中，针对高频边界情况进行了专项攻坚优化：

### 1. 统一请求层封装与无感拦截 (Axios Architecture)
- **Token 自动化注入**：在 Axios 请求拦截器中统一获取 LocalStorage/Cookie 中的身份凭证，并在 Header 中规范注入 `Authorization: Bearer <Token>`。
- **401 统一登出与过期平滑过渡**：响应拦截器集中拦截 HTTP 401 鉴权失效状态，清除本地脏数据，并记录当前页面 `redirect` 路由参数，登录后实现原路无感跳回。
- **全局网络异常兜底**：对网络超时、500 服务端内部错误统一触发 Vant `showToast` 或 Element Plus `ElMessage`，防止界面无响应或静默报错。

### 2. 动态路由权限与菜单高亮同步
- **基于权限表的路由动态添加**：管理员登录成功后，通过 `router.addRoute` 动态合并异步权限路由，实现“无权不可见、越权无法访”的双重安全防护。
- **解决刷新后路由高亮不一致**：监听当前路由变化动态绑定侧边栏 `default-active` 属性，解决刷新页面或多级子路由切换时菜单高亮丢失脱节的问题。

### 3. 严格的订单状态机与定时器生命周期治理
- **订单待支付倒计时封装**：抽象复用倒计时逻辑，精准计算服务端剩余毫秒数，避免客户端本地时间偏差导致的倒计时失真。
- **定时器内存泄漏防护**：在组件离开或用户返回上一页时，于 `onUnmounted` / `onBeforeUnmount` 钩子中严格执行 `clearInterval` / `clearTimeout`，杜绝因定时器后台常驻造成的内存泄漏和重复发请求。

### 4. 接口异常崩溃防御与防重复提交
- **请求防重提交机制**：针对用户狂点“立即预约”、“确认支付”等危险操作，通过响应式 `loading` 状态锁与防抖（Debounce）函数控制，避免短时间内向后端发送重复订单请求。
- **全量 TypeScript 类型守护**：为后端接口契约编写严密的类型接口（DTO 与 VO），对可能出现的 `null` 或 `undefined` 字段进行可选链（`?.`）与空值合并（`??`）处理，彻底杜绝前端 `Cannot read properties of undefined` 运行时白屏崩溃。

## 🚀 快速开始

### 运行环境准备
- **Node.js**：`>= 18.0.0` (推荐 LTS 20.x)
- **包管理工具**：推荐 `pnpm` 或 `npm`

### 1. 克隆代码仓库
```bash
git clone https://github.com/GQSSYY/移动医疗护送平台.git
cd 移动医疗护送平台
```

### 2. 启动运营后台管理端 (`pzadmin`)
```bash
# 进入后台管理端目录
cd pzadmin

# 安装依赖
npm install
# 或使用 pnpm
# pnpm install

# 启动本地开发服务
npm run dev

# 生产环境打包构建
npm run build
```
> 默认启动本地开发端口，通常为 `http://localhost:5173` 或对应配置端口，使用管理员账号登录体验。

### 3. 启动用户移动 H5 端 (`pzH5`)
```bash
# 进入移动端目录
cd ../pzH5

# 安装依赖
npm install
# 或使用 pnpm
# pnpm install

# 启动移动端开发服务
npm run dev

# 生产环境打包构建
npm run build
```
> 建议在 Chrome 开发者工具中切换至 **移动设备仿真模式**（如 iPhone 14 Pro / 390x844），以获得最佳视觉与手势交互体验。

## 📋 业务状态码参考说明

| 订单状态 | 状态码 | 对应操作与交互 |
| :--- | :---: | :--- |
| **待支付** | `10` | 开启 15 分钟支付倒计时，展示二维码，允许用户自主取消订单 |
| **待服务** | `20` | 用户支付成功，后台或系统分配陪诊师，陪诊师电话联系就诊人 |
| **服务中** | `30` | 陪诊师现场到达医院签到，开启全程陪诊记录 |
| **已完成** | `40` | 服务结束，就诊人对陪诊师进行星级打分与综合评价 |
| **已取消** | `50` | 支付超时自动取消或用户在履约前主动取消 |
